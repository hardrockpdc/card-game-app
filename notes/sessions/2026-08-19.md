## Decisions
- **Deferred the renormalize until it was asked for as its own task**, rather than riding
  it along on "push my commits" — a repo-wide line-ending commit needs its own diagnostic
  pass (§3.1). Filed as CQ-19, then fixed later the same session once it was the task.
- **Marked `archive/PROJECT_NOTES.md` as `-text` instead of excluding it by pathspec.**
  Both keep CLAUDE.md's freeze, but a pathspec exclusion would leave that one file
  permanently phantom-dirty; unsetting the attribute makes git stop converting it, so it is
  byte-identical *and* clean. The line must sit below `*.md text eol=lf` — last match wins
  per attribute.
- **Verified the smudge direction before trusting the fix**, with `git checkout-index
  --prefix` into a scratch directory rather than reasoning about it. `.js` checks out CRLF,
  `.md`/`.json` check out LF, blobs store LF. `npm test` is not evidence here —
  `--renormalize` writes to the index only, so Jest reads unchanged files off disk.
- **Put the SessionStart hook in project scope**, not `/config/.claude/settings.json`. It
  enforces a rule that lives in `CLAUDE.md`, so it belongs in the same committed, reviewable
  place. The merge risk this created was checked and cleared in `/hooks`.
- **Chose a hook over remembering.** The chat-style rule had already failed silently once
  this session — the style was imitated from `CLAUDE.md` while neither skill was loaded,
  which produces no error signal. Nothing in the harness auto-invokes skills; a
  `SessionStart` hook is the only mechanism that puts the instruction in context every time.
- **Did not restore the pre-`renormalize` "clean" `git status`.** The 123 files were always
  mismatched; the index stat cache was hiding it. Rewriting 123 files on disk to fix a
  display artifact costs more than it returns.
